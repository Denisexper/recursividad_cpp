# Chriseme se acaba los Tokens


¡Es un milagro! Ambos lados del fútbol y la programación se unieron para hacer frente al mal mayor y están a un paso de cumplir su objetivo.

Únicamente quedan el PFL Pleités, ya debilitado, y ClaugemEx, el líder de los Reapers. Odlanor, Issem y el resto de los héroes y villanos se enfrentarán al ejército Reaper, mientras que Chriseme se enfrentará a ClaugemEx, en un combate de astucia.

Chriseme se comunicará en el lenguaje ancestral de la máquina, y con él, cuestionará su ética hasta derrotarlo finalmente. Para traducir automáticamente el lenguaje humano al de las máquinas, Chriseme deberá utilizar 'tokens', y tú, debes ayudarle a calcular cuántos necesita.

Cada carácter tiene un costo, equivalente a su valor entero en la tabla ASCII, y el costo total de una oración será la suma de los costos de cada uno de sus caracteres. Sin embargo, como Chriseme utiliza el código de descuento "0d14n0r-3l-GOA7", recibirá un **10% de descuento** en su total.

¿Cuál es el costo final de enviar cada mensaje?

## Entrada

- La primera línea contiene un valor **N**, el tamaño de la cadena que quiere traducir Chriseme.
- La siguiente línea contiene una única cadena de caracteres, de tamaño **N**, el mensaje que envía Chriseme.

## Salida

Debes imprimir un valor: el costo final de enviar el mensaje. Como es dinero, asegúrate de imprimir **2 decimales siempre**.

## Restricciones

- 1 ≤ N ≤ 10⁵
- Todas las letras son parte del alfabeto inglés

## Casos de prueba

### Caso 1

**Entrada:**
```
1
a
```

**Salida:**
```
87.3
```

### Caso 2

**Entrada:**
```
5
abcde
```

**Salida:**
```
445.5
```
